# Лабораторная работа №3 — «Доска публикаций»

Асинхронный JavaScript и REST API (fetch, async/await, JSON, HTTP).

## Состав проекта

- `index.html` — разметка интерфейса
- `style.css` — оформление
- `app.js` — логика (GET, POST, валидация, обработка ошибок)
- `README.md` — этот файл

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере (двойной клик).
   Использовать локальный сервер не обязательно, но можно, например:
   `python -m http.server 8000` и открыть `http://localhost:8000`.
3. Для проверки запросов нужен доступ в интернет
   (API: https://jsonplaceholder.typicode.com).

## Результаты проверки

- **«Загрузить публикации»** → появляются 5 записей с заголовком и текстом (GET).
  Во время запроса показывается сообщение «Загрузка публикаций…».
- **Пустые поля или одни пробелы** → появляется ошибка валидации,
  запрос не отправляется.
- **Корректные заголовок и текст** → успешный ответ (HTTP 201),
  сообщение об успехе с заголовком и ID, карточка добавляется на страницу (POST).
- **Ошибка HTTP (проверка с /postz)** → при замене GET-адреса на
  `https://jsonplaceholder.typicode.com/postz` появляется сообщение об ошибке,
  кнопка снова активна и запрос можно повторить.
  После проверки адрес восстановлен на правильный.
- Сетевые сбои и неуспешные HTTP-ответы обрабатываются через
  `response.ok` и `try/catch/finally`.

## Технические детали

- Чистый HTML/CSS/JS, без фреймворков.
- Текст выводится через `textContent` (защита от XSS).
- Страница не перезагружается, форма использует `preventDefault()`.
- Данные POST: `{ title, body, userId: 1 }`, заголовок `Content-Type: application/json`.
- JSONPlaceholder имитирует создание: новые записи не сохраняются на сервере постоянно.
